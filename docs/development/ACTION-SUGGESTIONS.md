# 行动卡动态生长与下一步对话提案实施规范

> 文档性质：实施规范，不记录当前完成进度。当前进度只以根目录 [`STATUS.md`](../../STATUS.md) 为准。
> 视觉约束一律以 [`../design/UI-DESIGN.md`](../design/UI-DESIGN.md)（纸墨纪事）为准。

## 1. 背景

`database/postgres/action-state.ts` 的「观察四周」场景行动对所有世界无条件注入演示世界文案（防波堤/灯塔/雾港信号灯），新世界行动面板串场。同时每回合结束后缺少引导性的下一步方向。本批次修复行动卡文案硬编码，并新增回合后的下一步对话提案。

## 2. 行动卡动态生长

### 2.1 数据源

能力目录 SQL 的 `authorized_actor` CTE 按 record head 游标 LATERAL 取出当前场景行（与 delivery-projection 同一条游标选择规则），带出 `scene_location`，并取 `worlds.settings->>'weather'` 为 `scene_weather`；场景未生长（留白）时为 NULL。

### 2.2 文案契约（纯函数 compose*）

| 分支 | 有场景数据 | 留白（无场景数据） |
|---|---|---|
| 观察四周（scene） | description「留意{地点}一带的变化（{天气}）」（天气缺省不带括注）；suggestedText「我观察{地点}一带的变化。」 | 「留意周遭环境的变化。」/「我观察周遭的变化。」 |
| 密函技能（skill） | 描述取 `skill_definitions.description`（数据驱动），不再写死 | 同左（该分支本就按 demo 专属 key 过滤） |
| 资产（asset） | suggestedText 由资产自身 title 生成「我使用{title}。」 | 同左 |
| 姿态（stance） | 描述取 `effect_definitions.description`；suggestedText「我进入{title}，保持戒备。」 | 同左 |

铁律：任何分支不得出现演示世界的具体意象（防波堤/灯塔/雾港），除非它来自该世界自己的场景数据。demo 世界有场景数据，改后文案自然贴合其场景（如「留意灰鲸港 · 北防波堤一带的变化（冷雾，无风）」），不得退化为中性兜底。

## 3. 下一步对话提案

### 3.1 产出契约

- 旁白结构化输出 schema 扩展为 `{environment, storyBeat, suggestions}`，一次模型调用同时产出 2–3 条下一步对话提案，不增加额外请求。
- 提案要求：每条一句话（≤40 字）、以玩家身份第一人称、贴合当前剧情与玩家定位、不得泄露秘密信息、不得替玩家做重大决定。
- **fail-closed**：`suggestions` 缺失/非数组/规整后为空 → 按未提供处理；超 3 条截断；非法条目剔除。规整失败绝不影响旁白本体。
- 回合计划携带提案（`M2TurnPlan.nextSuggestions`）随命令载荷经运行时持久化；提交响应的信封附带 `suggestions` 返回前端；`loadRecord` 不带提案（刷新后消失，符合「提案属于当次回合」语义）。

### 3.2 UI 契约

- 交互方案：**点击提案 → 填入自由输入框并聚焦，由玩家确认后送出**（不直接提交）。理由：与既有草稿恢复/幂等路径共用一条提交通道，玩家在送出前可改字，避免误触直接落库——比点击即提交更稳。
- 样式：输入区上方的直角纸签（`--paper-soft` 底、1px `--line` 边、无硬阴影重效果），与行动卡（语义分层、能力徽章）视觉区分；轻量淡入（≤300ms）。
- 无提案时该区域整体不渲染，不留空占位；提案不替代自由输入。

## 4. fail-closed 矩阵

| 环节 | 失败形态 | 行为 |
|---|---|---|
| 行动卡文案 | 场景行缺失/字段为空 | 中性兜底文案，不编造意象 |
| 提案生成 | 模型未返回/格式不符/全非法 | 不显示提案，回合与输入照常 |
| 提案点击 | 输入框不可用（回合进行中） | 不填入（禁用态不渲染提案） |

## 5. 验收标准

1. Core 契约：行动描述合成各分支（有场景/留白/demo）、提案 schema 校验与 fail-closed。
2. PG 集成：新世界留白 → 中性兜底；demo 世界 → 贴合场景文案。
3. GUI O 组：新世界行动面板无 demo 文案、留白兜底、回合后提案浮现且点击填入可提交、无提案不渲染空区、自由输入不受影响；既有组全量回归。
4. `npm test` 全链绿；GUI 后执行测试数据清理。
